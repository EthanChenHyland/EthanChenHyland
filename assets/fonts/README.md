# Profile Mono font subset

Derived from IBM Plex Mono Regular (IBM/plex, SIL Open Font License 1.1).
The original font is available at:
https://github.com/IBM/plex/blob/master/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf

The renamed subset includes basic Latin, middle dot, en/em dash, ellipsis, and
right arrow. It is embedded in each generated SVG so layout does not depend on
external font requests. Original copyright and license records are preserved.
See `OFL.txt` for the full license.

Built with fonttools 4.59.2 and brotli 1.1.0, dropping hints and keeping the source
timestamp fixed. The committed WOFF2 means neither package is needed at runtime.
